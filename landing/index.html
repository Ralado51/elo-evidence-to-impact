O problemaThe problem

Texto fluente não é evidência.

Entre uma sessão e outra, ninguém vê o que a pessoa fez em casa. Um modelo de linguagem preenche esse vazio com frases convincentes, e a frase "fez sem ajuda" parece tão boa quanto a verdadeira.

Aqui, cada afirmação precisa de um fato registrado. O verificador refaz a conta a partir das evidências. Se não bate, não passa.

Caso demonstrativo sintético. Pode ser reproduzido no painel da terapeuta. Nesta demonstração, os textos vêm de modelos fixos e o "rascunho exagerado" é injetado de propósito; o rascunho por modelo de linguagem local é o próximo passo.

Fluent text is not evidence.

Between sessions, nobody sees what the person did at home. A language model fills that gap with convincing sentences, and "did it without help" reads as well as the true one.

Here every claim needs a recorded fact. The verifier recomputes from the evidence. If it does not match, it does not pass.

Synthetic demo case. You can reproduce it in the therapist dashboard. In this demo the texts come from fixed templates and the "exaggerated draft" is injected on purpose; drafting with a local language model is the next step.

Como decidimosHow we decide

Cada frase só pode subir até o nível que a evidência alcança.Each sentence can only go as high as the evidence reaches.

1

O movimento aconteceu. O registro do aparelho ou da câmera sustenta.

The movement happened. The device or camera record supports it.

2

O exercício prescrito foi feito, com validação.

The prescribed exercise was done, with validation.

3

Foi feito com independência: só com relato ou observação, sempre marcados como tal.

It was done independently: only with a report or an observation, always labelled as such.

4

Evolução funcional: decisão exclusiva da terapeuta.

Functional progress: the therapist's decision alone.

"Não observado" nunca vira "não fez". Quando faltam dados, o relato diz que faltam.

"Not observed" never becomes "did not do". When data is missing, the report says so.

Como foi feitoHow it was built

O mesmo princípio vale para quem construiu.

Uma fábrica de agentes dividiu o trabalho em três papéis: arquiteto, implementador e verificador, cada um em um modelo diferente. Quem escreve o código não o aprova. Contratos e verificações em código decidem o que entra, e uma pessoa aprova o que vai adiante.

The same principle applies to how it was built.

An agent factory split the work into three roles: architect, implementer and verifier, each on a different model. Whoever writes the code does not approve it. Contracts and code checks decide what gets in, and a person approves what moves on.

PrincípiosPrinciples
  • Dados inteiramente sintéticos na competição.
  • Só sessões iniciadas pela pessoa: sem monitoramento contínuo.
  • Sem diagnóstico, prescrição automática ou previsão clínica.
  • Nenhuma afirmação publicada sem revisão da terapeuta.
  • Entirely synthetic data in the competition.
  • Only person-initiated sessions: no continuous monitoring.
  • No diagnosis, automatic prescription or clinical prediction.
  • No statement published without therapist review.
